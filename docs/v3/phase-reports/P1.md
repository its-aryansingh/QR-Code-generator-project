## 2. What Was Built

### 2.1 Schema & Migrations (P1a, P1b, P1c)
- **23 Apps Configured & Models Registered:** Complete Django models matching Go v2 `reference/go-v2/db/migrations/00001` through `00007` plus Plan §6.4 deltas across all 23 apps.
- **Foreign Keys & DB Column Alignment:** Explicit `db_column` mappings for audit columns (`created_by`, `updated_by`, `requested_by`, `handled_by`, `granted_by`) ensuring exact column parity with Go v2.
- **Enterprise SQL Triggers & Procedures:**
  - `qrit_four_eyes_approval`: enforces that an approval requester cannot self-approve.
  - `qrit_audit_chain_prevent_update_delete`: guarantees tamper-evident append-only audit trail.
  - `qrit_next_invoice_number`: gapless sequential invoice numbering per organization.
  - `qrit_sync_org_plan_to_subscription`: keeps organization plan and subscription state consistent.
- **Partition Functions:** `qrit_ensure_scan_partitions` and `qrit_drop_scan_partitions` for monthly partitioning of `scan_events`.
- **Row-Level Security (RLS):** Policies created for all tenant-scoped tables ensuring strict workspace isolation via `qrit_current_workspace()`.
- **System Roles Seed:** Enterprise RBAC roles (`owner`, `admin`, `editor`, `analyst`, `billing_admin`, `viewer`) seeded with standard catalog permissions.

### 2.2 Core Utilities & Infrastructure (P1d)
- **`apps.core.db`:** `workspace_scope(ws_id)` context manager wrapping mutations in transactions with `SET LOCAL app.workspace_id`, supporting nesting and cleanup.
- **`apps.core.crypto`:** Envelope encryption `Keyring` using AES-256-GCM with 12-byte random nonce, KEK derived from `APP_ENCRYPTION_KEY`, AAD = org UUID bytes, automatic key rotation and DEK caching, `blind_index` via HKDF-SHA256 and HMAC-SHA256, and platform secret sealing/unsealing.
- **`apps.core.flags`:** Fast feature-flag evaluation (`enabled(key, org_id)`) with org-level overrides and TTL caching.
- **`apps.core.ratelimit`:** Redis sorted set sliding-window rate limiter with fail-closed/fail-open policies and thread-safe in-memory fallback.
- **`apps.core.net`:** Client IP resolution via `client_ip(request)` against Cloudflare edge CIDRs with spoof prevention and /24 IPv4, /48 IPv6 prefix truncation.
- **`apps.core.http`:** SSRF-safe HTTP client (`safe_client`, `async_safe_client`) with pre-resolution DNS filtering blocking private, link-local, CGNAT, loopback, and broadcast IP ranges.
- **`apps.core.pagination`:** Opaque URL-safe base64 `(created_at, id)` cursor pagination returning `{data, next_cursor}`.
- **`apps.core.idempotency`:** RFC/enterprise `Idempotency-Key` deduplication middleware validating key lengths (8–128 chars), bypassing safe methods, returning `Idempotent-Replayed: true` on replays, returning 422 on payload change, and returning 409 on concurrent in-flight requests.
