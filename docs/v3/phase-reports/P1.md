## 1. Plan

### 1.1 Goals & Sub-steps
1. **P1a — Baseline Schema & RLS:**
   - Implement `apps/core/ids.py` (`uuid7()` generator compatible with Python 3.13/3.14).
   - Implement `apps/core/fields.py` (`CIText`, `FixedCharField`, `CIDRField`).
   - Implement initial models and Django migrations for `00001_init` tables distributed across their respective apps:
     - `apps/accounts`: `User`, `OAuthAccount`, `Session`, `EmailToken`
     - `apps/workspaces`: `Workspace`, `WorkspaceMember`, `Invite`
     - `apps/qr`: `Domain`, `Folder`, `Tag`, `Campaign`, `Template`, `File`, `QRCode`, `ShortCodeTombstone`, `QRCodeTag`, `QRVersion`
     - `apps/analytics`: `ScanEvent` (`managed=False`), `ScanVisitorDaily`, `ScanStat15m`, `ScanStatDailyDim`
     - `apps/developer`: `ApiKey`
     - `apps/integrations`: `Webhook`, `WebhookDelivery`
     - `apps/billing`: `Subscription`, `BillingEvent`
     - `apps/audit`: `AuditLog`
     - `apps/trust`: `AbuseReport`
     - `apps/core`: `Job`, `IdempotencyKey`
   - Implement `00002_rls` migration (SQL `qrit_current_workspace()` function, `ENABLE/FORCE ROW LEVEL SECURITY`, tenant isolation policies).

2. **P1b — Enterprise Schema & Partition Maintenance:**
   - Note: Skip `00003_worker` (tables `job_queue` and `worker_task_runs` replaced by procrastinate; added to schema parity ignore list).
   - Implement models and migrations for `00004_enterprise`:
     - 42 enterprise tables (`organizations`, `org_members`, `org_domains`, `org_security_policies`, `roles`, `role_bindings`, `groups`, `group_members`, `sso_connections`, `user_identities`, `scim_directories`, `scim_users`, `approval_requests`, `approval_decisions`, `contracts`, `invoices`, `invoice_sequences`, `integrations`, `alert_rules`, `report_schedules`, `forms`, `form_submissions`, `pixels`, `gs1_items`, `serial_batches`, etc.).
     - SQL functions and triggers: audit sealing, plan sync, approval rules, invoice sequences.
     - `audit_logs.id` identity column.
     - `SECURITY DEFINER` partition functions: `qrit_ensure_scan_partitions` and `qrit_drop_scan_partitions`.
     - RLS tenant policies for all newly added tenant tables.

3. **P1c — Schema Fixes, v3 Deltas & Schema Parity:**
   - Implement migrations for `00005_identity`, `00006_governance`, `00007_billing`.
   - Implement Plan §6.4 v3 deltas (`legacy_id_map`, `legacy_import_runs`, `legacy_email_log`, `qr_codes.legacy_host`, `qr_codes.v1_printed_payload`, `organizations.grandfathered_limits`, `api_keys.legacy_bcrypt_hash`, `webhooks.signature_scheme`, `forms.legacy_slug`, `forms.presentation`, `subscriptions` partial unique index, `scan_events.source`).
   - Create `tests/test_schema_parity.py` comparing the Go migration catalog against Django migrations on PostgreSQL 17.
   - Generate `docs/v3/GO_TEST_PORT.md` inventory from all `func Test*` in `reference/go-v2/`.

4. **P1d — Core Enterprise Infrastructure:**
   - `apps/core/errors.py`: complete registration and DRF handlers.
   - `apps/core/pagination.py`: cursor-based base64url pagination.
   - `apps/core/idempotency.py`: middleware and storage matching Go behavior.
   - `apps/core/ratelimit.py`: Redis sliding-window/GCRA limiter.
   - `apps/core/net.py` & `apps/core/net/cloudflare_ranges.py`: client IP resolution and prefix truncation.
   - `apps/core/http.py`: SSRF-safe HTTP client (`safe_client`).
   - `apps/core/db.py`: `workspace_scope(ws_id)` context manager.
   - `apps/core/crypto/keyring.py`: envelope encryption, DEK management, blind indexing, platform sealing.
   - `apps/core/flags.py`: feature flags resolution and caching.
   - `apps/core/storage.py`: S3 SigV4 query presigning.
   - `apps/core/email.py`: Resend client & test backend.
   - `apps/core/events.py`: transactional outbox fanout deferral.
   - Multi-database router for `owner` database alias.
   - Management commands: `ensure_db_roles`, `ensure_redis_config`, `rotate_kek`.
