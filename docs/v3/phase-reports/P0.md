Lockfile resolved cleanly for 117 packages.
- **Entrypoints:** `manage.py`, `qrit/wsgi.py`, `qrit/asgi.py`, `qrit/procrastinate.py` (with standard queues: `critical`, `default`, `bulk`, `integrations`, `reports`).
- **Settings Architecture:**
  - `qrit/settings/env.py`: Pydantic settings loading all environment variables defined in plan Appendix A with typed validation.
  - `qrit/settings/base.py`: Common installed apps, middleware, psycopg3 pool configurations, structlog logging.
  - `qrit/settings/api.py`: REST framework configurations, auth, cookie security.
  - `qrit/settings/redirect.py`: Optimized redirect settings.
  - `qrit/settings/worker.py`: Procrastinate queue settings.
  - `qrit/settings/build.py`: Collectstatic configuration without DB requirement.
  - `qrit/settings/test.py`: Fast in-memory SQLite and mock cache for local fast test runs.
- **URL Routing:**
  - `qrit/urls/api.py`: OpenAPI schema, Swagger UI, Redoc, `/healthz`, `/readyz`, `/health`.
  - `qrit/urls/redirect.py`: Dedicated redirect routes.
- **`apps/core`:**
  - `apps/core/logging.py`: Structlog configuration and `get_logger` helper.
  - `apps/core/errors.py`: RFC 7807 `ApiError` base class, semantic helper functions (`not_found`, `forbidden`, `unprocessable`, `payment_required`, `conflict`, `rate_limited`), canonical error code registry, and custom DRF exception handler.
  - `apps/core/views/health.py`: Liveness probe (`/healthz`), readiness probe (`/readyz`) validating PostgreSQL connection and Redis ping, plus `/health` alias for Railway compatibility.
  - `apps/core/management/commands/wait_for_migrations.py`: Migration readiness polling for background workers and ingest containers.
- **Production Packaging:**
  - `backend/Dockerfile`: Multi-stage build (uv builder, collectstatic stage with `DJANGO_SETTINGS_MODULE=qrit.settings.build`, non-root user `qrit` UID 10001).
  - `backend/gunicorn.conf.py`: Configuration matching plan §4.3 and Railway deploy §3.3.
